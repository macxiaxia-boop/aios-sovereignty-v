# AIOS Kernel HTTP API Reference (R1505-1)

> **Base URL**: `http://127.0.0.1:9000` (default, configurable via `--port`)
> **Format**: JSON request/response · Prometheus exposition for `/metrics`
> **Version**: R1505-1

This is the production HTTP surface of the AIOS Kernel, built on FastAPI and
uvicorn. It exposes the `AIOSScheduler` for monitoring and inter-daemon
communication.

### Endpoints

| Method | Path | Purpose | Code |
|---|---|---|---|
| GET | `/health` | JSON liveness (legacy) | 200 |
| GET | `/healthz` | K8s liveness probe | 200 |
| GET | `/readyz` | K8s readiness probe (DLQ-based) | 200 / 503 |
| GET | `/metrics` | Prometheus exposition format | 200 |
| POST | `/tasks` | Submit a Task to the scheduler | 202 / 422 |
| GET | `/tasks/{run_id}` | Query task status | 200 |
| GET | — | `MCP tools/list` (JSON-RPC) | 200 |
| POST | — | `MCP tools/call` (JSON-RPC) | 200 |
| GET | `/docs` | OpenAPI Swagger UI (FastAPI built-in) | 200 |
| GET | `/openapi.json` | OpenAPI schema | 200 |

### `POST /tasks`

Submit a new Task to the AIOSScheduler.

**Request body**:
```json
{
  "goal_id": "string (required)",
  "title": "string (required, max 200 chars)",
  "description": "string (optional, max 4000 chars)",
  "priority": "P0 | P1 | P2 (default P2)"
}
```

**Response 202**:
```json
{
  "run_id": "run-<uuid>-<int>",
  "task_id": "<uuid>"
}
```

**Response 422** (invalid priority):
```json
{"detail": "string 'Z' is not a valid priority"}
```

### `GET /tasks/{run_id}`

Query a task's current state.

**Response 200**:
```json
{
  "run_id": "run-...",
  "state": "pending | running | completed | failed | cancelled | unknown"
}
```

### `GET /healthz` (K8s liveness)

Returns `200` when the kernel process is alive. No dependencies.

```json
{"status": "alive", "ts": 1731345678.901}
```

### `GET /readyz` (K8s readiness)

Returns `200` if the dispatcher is healthy and DLQ is below threshold.
Returns `503` (degraded) if DLQ exceeds 1000 entries.

```json
{"status": "ready", "dlq_size": 0, "submitted": 12, "completed": 10, ...}
```

### `GET /metrics` (Prometheus)

Exposes counters and gauges compatible with Prometheus 0.0.4:

```
# HELP aios_kernel_submitted_total Total tasks submitted since process start.
# TYPE aios_kernel_submitted_total counter
aios_kernel_submitted_total 12
aios_kernel_completed_total 10
aios_kernel_failed_total 0
aios_kernel_retried_total 2
aios_kernel_dlq_size 0
aios_kernel_avg_dispatch_latency_seconds 0.123
aios_kernel_circuit_opened_total 0
aios_kernel_queue_depth{priority="P0"} 0
aios_kernel_queue_depth{priority="P1"} 1
aios_kernel_queue_depth{priority="P2"} 1
```

### MCP (JSON-RPC over HTTP)

The kernel also exposes an MCP server on the same port via JSON-RPC 2.0:

#### `tools/list`
Returns 4 tools:
- `aios_submit_task`
- `aios_get_task_status`
- `aios_get_metrics`
- `aios_get_health`

#### `tools/call`
Request:
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {"name": "aios_submit_task", "arguments": {"goal_id": "g", "title": "t"}}
}
```

### Rate limiting

JWT-authenticated requests are token-bucketed per-worker:
- Default: 100 tokens, refills 10/sec
- See `aios_kernel.gateway.auth.RateLimiter`

### Authentication

JWT HS256, header: `Authorization: Bearer <token>`. See
`aios_kernel.gateway.auth.sign_jwt / verify_jwt`.

### Errors

| Code | When |
|---|---|
| 400 | Generic bad request |
| 401 | Missing or invalid JWT |
| 422 | Pydantic validation error (bad priority, missing field) |
| 429 | Rate limit exceeded |
| 500 | Internal scheduler error |
| 503 | Readiness probe failure (DLQ overflow) |

### Examples

```bash
# Health
curl http://localhost:9000/healthz

# Submit a task
curl -X POST http://localhost:9000/tasks \
  -H "Content-Type: application/json" \
  -d '{"goal_id":"g1","title":"prod-task","priority":"P1"}'

# Query status
curl http://localhost:9000/tasks/run-abc-123

# Prometheus metrics
curl http://localhost:9000/metrics

# MCP tools/list
curl -X POST http://localhost:9000 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
