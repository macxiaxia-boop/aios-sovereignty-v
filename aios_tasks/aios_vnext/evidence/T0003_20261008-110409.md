```powershell
33:     $staleMsg = "STALE_HANDOFF: generated=$generatedAt expires=$expiresAt now=$now"

```

### 3.3 Why `-ErrorAction SilentlyContinue`

`D:\demo\start-cc-current.ps1` line 1 sets `$ErrorActionPreference = 'Stop'`. Under `Stop`, a bare `Write-Error` becomes a terminating `WriteErrorException`, which causes the script to exit with **code 1** instead of honoring the `exit 42` two lines down. Empirical proof: the first stale-rejection test (without `-ErrorAction SilentlyContinue`) exited with code **1** and the runtime flagged `Write-Error` as a terminating exception. After the fix, the same test exited with code **42**.

Without the `-ErrorAction SilentlyContinue`, the original `Write-Error` form **never satisfied the exit-code acceptance criterion**. So the fix is non-cosmetic and required.
