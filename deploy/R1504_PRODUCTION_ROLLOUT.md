## 🚀 Quick Start (Docker Compose — recommended)

```bash
cd D:/AIOS/kernel

# 1. Set DB password
export AIOS_DB_PASSWORD="<strong-password>"

# 2. Build image
docker compose build

# 3. Start in background
docker compose up -d

# 4. Verify
curl http://localhost:9000/health
# → {"ok": true, "service": "aios-gateway", "version": "R1503"}

# 5. Submit a task via HTTP
curl -X POST http://localhost:9000/tasks \
  -H "Content-Type: application/json" \
  -d '{"goal_id": "g1", "title": "prod-task", "priority": "P1"}'
# → 202 {"run_id": "...", "task_id": "..."}

# 6. Tail logs
docker compose logs -f kernel
```

## 🚀 Quick Start (systemd — Linux)

```bash
# 1. Install kernel to /opt
sudo mkdir -p /opt/aios-kernel
sudo cp -r . /opt/aios-kernel/
cd /opt/aios-kernel
sudo python -m venv .venv
sudo .venv/bin/pip install -e .

# 2. Install systemd unit
sudo cp deploy/aios-kernel.service /etc/systemd/system/
sudo systemctl daemon-reload

# 3. Enable + start
sudo systemctl enable --now aios-kernel

# 4. Verify
sudo systemctl status aios-kernel
journalctl -u aios-kernel -f
```

---

## 🚀 Quick Start (supervisord)

```bash
sudo apt install -y supervisor
sudo cp deploy/aios-kernel.supervisord.conf /etc/supervisor/conf.d/aios-kernel.conf
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl status aios-kernel
```

## 🔧 Production hardening (DONE)

- ✅ Airgap network enforced (`internal: true`)
- ✅ No external API calls (`AIOS_KERNEL_NO_EXTERNAL_APIS=1`)
- ✅ Healthcheck endpoint (`/health`)
- ✅ Restart on crash (`--restart=unless-stopped`)
- ✅ Read-only filesystem hardened (systemd ProtectSystem)
- ✅ Logs to stdout/stderr (Docker) or journald (systemd)

## 📊 Performance budget

- Cold start: < 5s (Python + deps pre-installed in image)
- HTTP latency: < 50ms p95 (FastAPI + uvicorn single worker)
- Memory: ~200MB baseline (kernel only, scales with concurrent tasks)
- Disk: < 1GB (kernel + deps, no ML models)

- [ ] Network is internal-only (`internal: true`)
- [ ] TLS terminated at reverse proxy (Nginx/Caddy) — kernel itself runs HTTP
