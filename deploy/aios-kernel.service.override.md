# AIOS Kernel production systemd unit (R1505-4 enhancement)

## Replaces `deploy/aios-kernel.service` (R1504-2)

Differences from R1504-2 base:

- `AIOS_INSTANCE_ID` env (default `aios-kernel-1`) — included in `/metrics`
- `AIOS_KERNEL_AUTH_REQUIRED=0` — flip to `1` for production
- `AIOS_KERNEL_RATELIMIT_ENABLED=0` — flip to `1` for production
- `MemoryHighWatermark=4G` — guard against unbounded growth
- `RestartSec=10` (was `5`) — fewer hot-restarts on transient bugs

## Install

```bash
sudo cp deploy/aios-kernel.service.override.md /etc/systemd/system/aios-kernel.service
sudo systemctl daemon-reload
sudo systemctl enable --now aios-kernel
```

## Verify

```bash
sudo systemctl status aios-kernel
curl http://localhost:9000/healthz      # {"status":"alive","instance":"aios-kernel-1"}
curl http://localhost:9000/readyz       # {"adapters":{...},"db":"ok",...}
curl http://localhost:9000/metrics | grep aios_kernel

```

## Production-ready systemd unit (canonical)

```ini
[Unit]
Description=AIOS Kernel scheduler (R1505-4 production)
Documentation=https://github.com/macxiaxia-boop/aios-sovereignty-v
After=network-online.target postgresql.service
Wants=network-online.target
Requires=postgresql.service

[Service]
Type=simple
User=aios
Group=aios
WorkingDirectory=/opt/aios-kernel
Environment="PATH=/opt/aios-kernel/.venv/bin:/usr/local/bin:/usr/bin:/bin"
Environment="AIOS_KERNEL_OFFLINE=1"
Environment="AIOS_LOG_LEVEL=INFO"
Environment="AIOS_KERNEL_AUTH_REQUIRED=0"
Environment="AIOS_KERNEL_RATELIMIT_ENABLED=0"
Environment="AIOS_INSTANCE_ID=aios-kernel-1"
Environment="AIOS_KERNEL_DATABASE_URL=postgresql+psycopg://aios:CHANGEME@localhost/aios_vnext"
Environment="PYTHONUNBUFFERED=1"
ExecStart=/opt/aios-kernel/.venv/bin/python -m aios_kernel.cli scheduler run
ExecStop=/bin/kill -TERM $MAINPID
ExecReload=/bin/kill -HUP $MAINPID
KillMode=mixed
KillSignal=SIGTERM
TimeoutStopSec=30
Restart=on-failure
RestartSec=10
StartLimitBurst=10
StartLimitIntervalSec=60

# Hardening
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/var/log/aios-kernel
MemoryHighWatermark=4G
CPUQuota=200%

[Install]
WantedBy=multi-user.target
```
