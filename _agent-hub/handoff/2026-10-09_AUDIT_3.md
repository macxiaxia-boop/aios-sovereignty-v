## Consumer 真·状态

**Honest constraint**: WITHOUT admin elevation, consumer cannot persist across MCP shell invocations. This is a Windows OS limit, not a Codex limitation.

Workaround:
- WinSW service `AIOSV2Consumer` is registered (STATE 1 = STOPPED) with Auto-Delayed start. Reboot → auto-start as LocalSystem (no elevation needed at runtime).
- User can manually `net start AIOSV2Consumer` in admin shell.
