## Memory Block

**工作背景**
用户是 CloudTech 科技创始人/产品负责人，独立主导"AI 数字营销中台"项目，代码资产位于 D:\个人文件\AI\Operator\。并行运营灵策AI（自研数字员工 SaaS，70% 营销 + 30% 企业管理）与灵策智算（外采渠道产品）两条业务。当前核心任务：基于 CloudTech 半成品文档开发完整 AI 营销 SaaS 产品，定位 100% 超越灵策智算与 WorkBuddy 的全部 GO 功能与产品层。对标基准——灵策（15 agents / 46 real skills）、WorkBuddy（16+ MCP connectors、memory system、skill self-accumulation）。CloudTech 独有资产：1,989 篇竞品情报文档、2,421 篇 SaaS 语料、600+ 篇行业垂直文档（家居/医美）、多租户 SaaS、RBK、计费、私有化部署。

**个人背景**
用户沟通偏好简体中文，输出形式倾向结构化（表格 / 列表），要求 AI 直接给出明确判断而非空泛确认；称 AI 为"哥"，偏好简洁直接、加粗核心结论的报告风格。

**当前关注**
按既定两阶段路线推进产品交付：Phase 1 聚焦行业 SaaS（医美 + 装企）MVP 先完成闭环，Phase 2 再升维至工具型平台。当前重心在于消化半成品文档、补齐产品功能模块、明确对标差距，并规划抢先布局方向以确保行业 MVP 可落地、可超越灵策智算与 WorkBuddy 现有水平。

**近期动态**
- 明确两阶段路线：Phase 1 行业 SaaS（医美+装企）→ Phase 2 工具型平台升维，整体产品定位为营销型 SaaS。
- 锁定双对标基准：灵策（15 agents / 46 real skills）vs WorkBuddy（16+ MCP connectors、memory system、skill self-accumulation），要求逐项拆解找差距并提出抢先布局方向与可行性评估。
- 沉淀并盘点 CloudTech 独有资产：1,989 篇竞品情报、2,421 篇 SaaS 语料、600+ 行业垂直文档（家居/医美）、多租户 SaaS、RBK、计费、私有化等差异化能力。
- 启动基于 CloudTech 半成品文档的完整 AI 营销 SaaS 产品开发，代码资产持续沉淀于 D:\个人文件\AI\Operator\。
- 持续运营 CloudTech 科技、灵策AI（数字员工 SaaS）、灵策智算（外采渠道）三条业务线。
- 沟通风格固化：要求端到端自主推进（"全部执行/落地"），无需逐步确认；深度分析工作流=运行逻辑+边界 case → 完整修复方案 → 一次性全量执行。
- 排查个人电脑 wmic.exe 反复弹窗问题：Windows 环境跑多个 AI 框架启动脚本（AIOS、hermes、OpenClaw 等），根因未定位，常以"继续"触发后续排查。
