## 4. 新 Manifest 首跑计划

| 阶段 | 内容 |
|------|------|
| Dry-run | R176 manifest 新版基于 restic snapshots --tag aios-portable --json 输出生成, 仅一次 dry-run, 不覆盖 |
| 验证 | 路径计数 + 总字节数 vs T0004 新 snapshot 64e1c1ed (266759 files, 88.632 GiB) |
| Atomic switch | R176 manifest 新版覆盖旧版, 用 `Copy-Item + Move-Item` 两步确保 atomic |
| 停止条件 | (1) Dry-run 与 restic output diff > 5%; (2) Manifest > 5MB (旧版 4.1MB); (3) Files 数量差异 > 10%; 任一发生 abort |

## 5. Sampling 后端选择策略

- **单次 sample** 必须显式选 1 个后端（`restic` 或 `legacy` 或 `none`）
- 跨后端 sample → FAIL + 警告
- 退役路径 sample → FAIL + 警告（标 `RETIRED` 后端）
- **dry-run flag**: `--dry-run` 列出将采样的路径, 不实际验证

T0006 已实施此策略: `_aios_backup_sampling_v2.py` 加 `select_backend(sample_request)` 函数。
