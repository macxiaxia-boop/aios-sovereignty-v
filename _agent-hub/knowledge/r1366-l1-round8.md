## 二、算法说明

### 4 维 base score (满分 10)
- **worldview_score** (满分10): 是否有清晰世界观
- **formula_score** (满分10): 是否有核心公式
- **creed_score** (满分10): creed_count≥5 → 10; creed_count<5 → 5
- **framework_score** (满分10): framework_count≥3 → 10; framework_count<3 → 5
- **base = (worldview + formula + creed + framework) / 4**

### 加分项
- **R1356 真用加分 +0.5**: version=4.0 的能力库均为 R1356 真用 v4 完整版 (≥400行)，全13个均满足

### 评分公式
```
overall = min((worldview + formula + creed_dim + framework_dim) / 4 + 0.5(真用) + 0.5(营销), 10.0)
```

### creed/framework 降维规则 (区分度高)
- **creed_score**: creed_count ≥ 12 → 10; 5≤count<12 → 5 (R226 v4: 12条creeds为满分基准)
- **framework_score**: framework_count ≥ 3 → 10; 2≤count<3 → 5
